# Software de aplicación

## Idea central
El software de aplicación es el conjunto de programas que el usuario utiliza para realizar tareas concretas, como editar un texto, navegar por la web o reproducir contenido. No gestiona directamente el hardware ni sirve para crear otros programas: se apoya en el software de sistema para hacer su trabajo y responde a una finalidad visible para la persona que lo usa.

## Antes de empezar
- [[software]]: qué es el software y por qué se divide en cuatro grupos según su función.

## Explicación
Desde [[software]] se sabe que el software son instrucciones y datos que indican al [[hardware]] qué debe hacer, y que se clasifica por función. El software de aplicación ocupa el lugar más cercano a la persona: es el programa que se abre para escribir, consultar información, comunicarse o entretenerse. Su valor no está en controlar recursos ni en traducir lenguajes, sino en resolver una tarea concreta en un lenguaje comprensible para el usuario, con ventanas, menús, documentos o mensajes.

La diferencia con el [[software-de-sistema]] es de finalidad. El software de sistema existe para que el ordenador funcione y para gestionar sus recursos; el de aplicación existe para que la persona haga algo con el ordenador. Por eso una aplicación no necesita conocer cómo se asigna la memoria o cómo se atiende una interrupción: solicita servicios al sistema y le entrega el resultado de su trabajo. Cuando una aplicación necesita leer un documento o mostrar una imagen, lo hace mediante los servicios que el sistema pone a su disposición, sin ocuparse de los detalles físicos de esa operación.

La diferencia con el [[software-de-programacion]] es de dirección. El software de programación sirve para crear y preparar otros programas, mientras que el de aplicación sirve para usar programas ya creados. Un editor de texto y un entorno de desarrollo pueden tener en común que ambos muestran texto en pantalla, pero su propósito es distinto: uno está pensado para redactar documentos y el otro para escribir y comprobar programas. Que una herramienta de programación también pueda ser usada como aplicación no borra esa distinción, porque lo que define a cada grupo es la función principal que cumple.

En conjunto, las aplicaciones forman un repertorio muy amplio y panorámico: edición de documentos, navegación por la web, reproducción de audio y vídeo, gestión de mensajes o cálculo de hojas de datos son ejemplos genéricos de esa diversidad. Lo común a todas ellas es que traducen una intención del usuario en una secuencia de operaciones que el sistema ejecuta, y que devuelven el resultado en una forma que la persona puede entender y aprovechar.

## Cómo se conecta con lo anterior y lo siguiente
Desde [[software]] se desciende a este grupo por función: si el software de sistema gestiona el hardware y el de programación permite crear software, el de aplicación es el que se usa para trabajar con el ordenador. Esta nota cierra el recorrido de los cuatro grupos en nivel panorámico; no abre todavía un camino lineal hacia un siguiente peldaño, porque el detalle de cada tipo de aplicación queda pendiente de su propia nota.

## Límites de esta explicación
Esta nota no desarrolla cómo funcionan los programas del [[software-de-sistema]], ni cómo se crean los programas con el [[software-de-programacion]]. Tampoco detalla cada clase de aplicación, su interfaz o sus archivos: esas cuestiones pertenecen a notas específicas de aplicación, aún no registradas, y a [[formatos-de-archivos]] y [[estructuras-de-datos]] cuando se trate de cómo una aplicación lee y guarda la información.
